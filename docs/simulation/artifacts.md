# Simulation Artifacts

Runs publish under `backend/artifacts/simulation/runs/<run-id>/`. A run ID is the first 20 hexadecimal characters of the canonical schema-version-2 simulation-run-config SHA-256. The run contract includes `simulator_version=sim-1.2`; strategy, market, path-config, and path hashes; selected policy parameters; separate option and futures cost configurations; runtime kill-switch state; accounting tolerance; and quantity-rounding convention. Simulator and run-schema versions participate in the hash, so an otherwise identical legacy run cannot collide. The contract is deterministic and contains no wall-clock value or artifact path.

The store writes a running manifest as soon as deterministic run identity exists, then writes artifacts under `.tmp-<run-id>` and atomically renames the directory. Contract-selection, engine, and reconciliation failures after identity publish an immutable failed manifest. Selected expiry, strike, and executable-state hash remain null if failure occurs before they are known and are populated only after successful execution. Failures before identity remain CLI validation errors. Temporary directories are never listed.

Each completed run contains `manifest.json`, `strategy-config.json`, `market-config.json`, `run-config.json`, `path-config.json`, `path.csv`, `market-states.csv`, `option-valuations.csv`, `hedge-decisions.csv`, `risk-decisions.csv`, `order-intents.csv`, `fills.csv`, `ledger.csv`, `positions.csv`, `pnl-attribution.csv`, and `summary.json`.

The schema-version-2 manifest records strategy, market, path config, underlying path, executable market-state, policy config, option cost, futures cost, runtime risk, and run-config hashes. `manifest_schema_version` describes this payload shape independently of `simulator_version`. It also records the complete clock config, selected expiry and strike, both multipliers, futures delta per contract, accounting tolerance, rounding convention, source commit, runtime timestamps, and artifact location. Running and failed manifests may retain null post-selection values; completed manifests require them. Failed runs retain every field known at failure time. `market-states.csv` contains the exact sequence covered by `executable_market_state_hash`; local timestamps retain the exchange offset and UTC timestamps remain explicit. Decision and risk CSVs include timed delta fields, quantities and counts, and position/session P&L. Generated run directories are ignored and are never source artifacts.
